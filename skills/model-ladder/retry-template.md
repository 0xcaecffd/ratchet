## What makes a retry useful

- **A different shape.** Name the failed shape and say what to do instead (smaller steps, a
  different tool, a narrower unit). A retry that repeats the shape wastes a rung.
- **A smaller unit.** If one unit failed twice, split it; each part starts at rung 1.
- **No rework.** Verified units are inputs by reference. If the retry regenerates them, the
  records were not read — fix the prompt, not the model.
- **An honest stop.** The agent records the class and shape and stops. The parent climbs; the
  agent never re-dispatches itself.
